IT314 Lab 8 – Run Instructions

Requirements
- Java JDK 17 or newer (tested with OpenJDK 21).
- No external libraries are required.

Folder structure
- src/Main.java
- src/Booking.java
- src/BookingState.java
- src/Payment.java

Compile and run the interactive CLI
1. Open a terminal in the extracted submission directory.
2. Run:
   cd src
   javac *.java
   java Main
3. Use menu options 1–7 to create/view a booking and trigger events. Option 8 runs all automated tests. Option 9 exits.

Run all automated required tests directly
   cd src
   javac *.java
   java Main --tests

Expected result
The test driver executes TC01 through TC07 and prints PASS for each test followed by OVERALL RESULT: PASS. The generated .class files are build outputs and are not part of the ZIP submission.
